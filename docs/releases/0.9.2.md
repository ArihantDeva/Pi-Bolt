Pi-Bolt 0.9.2 makes streaming cheaper and memory smaller: a long answer, a large file written through a tool call, and the
frames in between take less CPU, and on Linux the startup peak is up to 30% lower. What Pi draws and does is unchanged.
Everything else is [0.9.1](0.9.1.md).

Measured on GitHub's runners (one CPU, against 0.9.1's release builds; x86-64 / ARM64):

| | 0.9.1 | 0.9.2 | Pi on stock Bun |
|---|---|---|---|
| Streaming a 60,000-character answer, CPU s | 4.53 / 4.73 | 3.06 / 3.16 | 3.17 / 3.31 |
| A 400 KB file written through a tool call, CPU s | 3.54 / 3.71 | 2.79 / 2.61 | 3.01 / 2.75 |
| The same in tmux (write:50), Pi / tmux CPU s | 2.94 / 0.47, 2.93 / 0.33 | 1.43 / 0.29, 1.16 / 0.24 | 1.82 / 0.29, 1.49 / 0.24 |
| Startup peak memory, MB | 64 / 42 | 45 / 41 | 51 / 57 |
| Headless prompt peak memory, MB | 123 / 109 | 112 / 108 | 119 / 122 |

### Streaming

- **A long answer:** a chunk's frame no longer costs time in proportion to the length of the message. The Markdown of the blocks
  that did not change is kept, and the TUI no longer compares the whole message with the previous frame line by line.
- **A large tool call:** a chunk of a tool call's arguments draws a frame only when the arguments shown change. A 400 KB file used
  to draw thousands of identical frames.
- **Every frame:** the input area (editor, status, footer) is drawn once a frame instead of twice, and the spinner's line once per
  spinner frame.

### Memory on Linux

Where transparent huge pages are `always` (the default on many distributions), the part of the prebuilt heap's region that is
used sparsely took a 2 MB page for every page touched: about 11 MB more at startup. It now takes small pages. Where they are
`madvise`, nothing changes.

### Fixes

- **Ahead-of-time compiling:** a function whose constants add up to a number that happens to be an address in the compiling
  process (on macOS, in the system libraries' shared region) is compiled, no longer refused. A build of Pi, or `pi-bolt
  compile`, could fail on it on some machines.
- **Editor:** a wide character in an editor 1 column wide no longer overflows the stack.

### Engine

All four runtimes are new, built by the `runtime` workflow on GitHub's runners: the memory change and the compiler fix above.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`.
