Pi-Bolt 0.9.3 is Pi 1.3.0, compiled ahead of time. Everything else is [0.9.2](0.9.2.md).

### Pi 1.3.0

- **Clean model switching:** thinking from an earlier model is dropped instead of being shown to the new model as text.
- **Resumed sessions keep their active tools**; `--tools +name` and `-name` apply on top of them.
- **Kimi Code over Chat Completions:** tools added mid-conversation no longer invalidate the prompt cache. A `models.json` base
  URL override for `kimi-coding` must now end in `/v1`.
- **`/share`** can upload to a GitHub gist or Radius (`sessionShareDestination`).
- **Thinking level changes on OpenAI GPT-6** (API key) keep the prompt cache.
- Fixes to tool-call arguments with invalid `\u` escapes or malformed JSON, Claude requests with images in an error tool result,
  automatic retry on gateway errors, `--model` when several providers offer a model, OpenCode Go, Gemini, Xiaomi MiMo and
  more: Pi's [1.3.0 changes](https://github.com/earendil-works/pi/releases/tag/v1.3.0).

### Pi-Bolt

- **Termux from Google Play:** the installer says that this build has no glibc packages and to install Termux from F-Droid or
  GitHub, instead of failing in `pkg`. It also fetches Termux's package lists before installing glibc.
- The model catalog is Pi 1.3.0's, and the training profile is recorded for Pi 1.3.0.

### Engine

The runtimes are 0.9.2's: the engine has not changed.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`.
