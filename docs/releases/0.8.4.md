Pi-Bolt 0.8.4 lets Pi-Bolt and Pi share one setup without getting in each other's way, and makes installing on Windows smoother.
Everything else is [0.8.3](0.8.3.md).

### Pi and Pi-Bolt side by side

- **Pi-Bolt never changes the packages Pi loads.** Both use `~/.pi/agent` (logins, models, settings, sessions). Until you
  install or remove a package with `pi-bolt`, Pi-Bolt loads the packages in `settings.json` as Pi does; the first such change
  gives Pi-Bolt a list of its own (`piBolt.packages`, made from Pi's) and changes only that. A package you install with
  `pi-bolt install` is Pi-Bolt's; one you install with `pi install` is Pi's.
- **OpenSec's extensions load in Pi-Bolt only.** `opensec-pi-subagents`, `opensec-pi-todo` and `opensec-pi-fff` are built for
  Pi-Bolt's runtime, and Pi on Node cannot load them. Earlier installers added them to the list Pi reads too, so Pi started
  with "Failed to load extension" for each. Pi-Bolt moves them to its own list as it starts, and the installers have it do so
  right after installing: update Pi-Bolt (`pi-bolt update`) and Pi starts cleanly again.
- [README: Pi and Pi-Bolt side by side](../../README.md#pi-and-pi-bolt-side-by-side).

### Windows

- The install commands are `irm https://pi-bolt.opensec.in/install.ps1 | iex` in PowerShell and
  `powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"` in Command Prompt. The longer command the README and the
  site showed for a day, which turned TLS 1.2 on first, was blocked by Microsoft Defender; an older Windows 10 that needs TLS
  1.2 for the first download has two lines on the docs' Installation page.
- Installing or updating from a PowerShell 7 prompt works: `install.ps1` uses Windows PowerShell's own modules first (thanks to
  @Vlyn, #14).

### Releases

- A `publish` run again for a release, to put the site and the installers up again, skips the `pi-bolt` version npm has.

### Engine

Unchanged since 0.8.3: this release's runtimes are [0.8.3's](0.8.3.md#the-runtimes).

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`.

| Asset | For |
|---|---|
| `pi-bolt-linux-x64.tar.xz` / `.tar.gz` | **Recommended on Linux.** CPUs with AVX2 (Intel Haswell 2013+, AMD Zen+). |
| `pi-bolt-linux-x64-baseline.tar.xz` / `.tar.gz` | Any x86-64 CPU with SSE4.2. |
| `pi-bolt-linux-x64-jit.tar.xz` / `.tar.gz` | JIT also on, for plugins loaded at run time. |
| `pi-bolt-darwin-arm64.tar.xz` / `.tar.gz` | **macOS.** Macs with Apple silicon, macOS 13 or later. |

| `pi-bolt-runtime-linux-x64.tar.gz`, `pi-bolt-runtime-darwin-arm64.tar.gz`, `pi-bolt-runtime-win32-x64.zip` | The Pi-Bolt Bun runtime, for compiling plugins in. |

Linux x86-64 with glibc 2.17 or later; macOS 13 or later on Apple silicon; Windows 10 1809 or later, or Windows 11, on x64.
