Pi-Bolt 0.8.8 runs on Linux on ARM64 (Raspberry Pi, AWS Graviton, Ampere, ARM laptops) and on Android phones in Termux. Everything
else is [0.8.7](0.8.7.md).

### Linux on ARM64

The same installer picks the ARM64 build on an `aarch64` machine:

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

- **One build for every 64-bit ARM CPU.** Its code is for ARMv8.0, so it runs compiled on a Raspberry Pi 3 as on Graviton 4;
  `pi-bolt-linux-arm64-jit` adds the JIT, for plugins loaded at run time.
- **Any ARM64 kernel:** 4, 16 or 64 KB pages, and the 512 GB address space of Android's and the Raspberry Pi's kernels.
- **glibc 2.17 or later**, with its own ICU, as on x86-64: checked in the userlands of CentOS 7, Debian 9 and Amazon Linux 2, and on
  emulated Cortex-A53, Cortex-A72 and Neoverse N1 CPUs.

Against Pi 1.2.0 on stock Bun 1.4.2 and on Node 24, on the same machine (Linux arm64 on an Apple M5, four cores; medians of 15
runs, [BENCHMARKS.md](https://github.com/opensec-git/Pi-Bolt/blob/pi-bolt/docs/BENCHMARKS.md#linux-on-arm64)):

|  | Pi-Bolt 0.8.8 | Pi on Bun | Pi on Node 24 |
|---|---:|---:|---:|
| `pi --version` | 5 ms | 10 ms | 83 ms |
| `pi -p`: one prompt, 4 tool calls | 27 ms | 52 ms | 142 ms |
| Launch to interactive (TUI) | 29 ms | 45 ms | 114 ms |
| CPU of an interactive session (5 prompts) | 115 ms | 316 ms | 401 ms |
| Peak memory, interactive session | 129 MB | 157 MB | 179 MB |
| Own memory, tmux session | 37 MB | 75 MB | 79 MB |

### Android (Termux)

In [Termux](https://termux.dev), the same `curl ... | sh`. Pi-Bolt is a glibc program, so the installer installs Termux's glibc
(`pkg install glibc-repo && pkg install glibc`, after asking), sets it as the executable's loader, and links `pi-bolt` into
`$PREFIX/bin`. `pi-bolt` starts Pi-Bolt in Android's time zone and without Termux's `LD_PRELOAD`, which the programs it starts
get back. Where Android's system call filter refuses a call the runtime makes, it gets ENOSYS and the runtime falls back, as on an
older kernel. This was checked in a Linux container made to look like Termux on Android (`tests/termux/run.sh`), not yet on a
phone: reports are welcome.

### Engine

All four runtimes are new; on Linux x86-64, macOS and Windows they behave as 0.8.7's.

- **Linux ARM64:** the prebuilt heap and the compiled code are at 128 GB and laid out in 64 KB pages; `BUN_AOT_CPU=baseline`
  compiles for ARMv8.0; the Structures' first block follows the size of a heap block, which is 64 KB there.
- **Android:** a call the system call filter refuses returns ENOSYS, also when a JavaScript listener has `SIGSYS`.
- The runtimes are built on GitHub's runners, each on its own platform, by the new `runtime` workflow.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`.

| Asset | For |
|---|---|
| `pi-bolt-linux-x64.tar.xz` / `.tar.gz` | **Recommended on Linux x86-64.** CPUs with AVX2 (Intel Haswell 2013+, AMD Zen+). |
| `pi-bolt-linux-x64-baseline.tar.xz` / `.tar.gz` | Any x86-64 CPU with SSE4.2. |
| `pi-bolt-linux-x64-jit.tar.xz` / `.tar.gz` | JIT also on, for plugins loaded at run time. |
| `pi-bolt-linux-arm64.tar.xz` / `.tar.gz` | **Linux on ARM64**, any 64-bit ARM CPU; Android in Termux, with the installer. |
| `pi-bolt-linux-arm64-jit.tar.xz` / `.tar.gz` | Linux on ARM64, JIT also on. |
| `pi-bolt-darwin-arm64.tar.xz` / `.tar.gz` | **macOS.** Macs with Apple silicon, macOS 13 or later. |
| `pi-bolt-darwin-arm64-jit.tar.xz` / `.tar.gz` | macOS, JIT also on. |
| `pi-bolt-win32-x64.zip` | **Windows.** Windows 10 (1809) or 11 on x64; compiled code on AVX2 CPUs, bytecode on others. |
| `pi-bolt-win32-x64-jit.zip` | Windows, JIT also on. |
| `pi-bolt-runtime-linux-x64.tar.gz`, `pi-bolt-runtime-linux-arm64.tar.gz`, `pi-bolt-runtime-darwin-arm64.tar.gz`, `pi-bolt-runtime-win32-x64.zip` | The Pi-Bolt Bun runtime, for compiling plugins in. |

Linux x86-64 or ARM64 with glibc 2.17 or later; Android 7 or later on 64-bit ARM, in Termux; macOS 13 or later on Apple silicon;
Windows 10 1809 or later, or Windows 11, on x64.
