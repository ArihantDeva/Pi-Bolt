Pi-Bolt 0.9.0 is [0.8.8](0.8.8.md) after a review of the Linux ARM64 and Android ports: the prebuilt heap moves where no kernel
layout puts anything, and Android's system call filter cannot end a process during a synchronous spawn. Everything else is 0.8.8.

### Linux on ARM64

- **The prebuilt heap and compiled code are at 64 GB** (to 100 GB, with the Structures). At 128 GB they could meet the shared
  libraries of a process started with an unlimited stack (`ulimit -s unlimited`), which a 39-bit kernel then maps from 128 GB up,
  and Pi-Bolt would then run from bytecode.

### Android (Termux)

- A synchronous spawn (`execFileSync`, `spawnSync`) no longer takes over `SIGSYS` while the child runs, so a call Android's system
  call filter refuses meanwhile, on another thread, returns ENOSYS as at any other time.

### Engine

All four runtimes are new, built by the `runtime` workflow on GitHub's runners; on Linux x86-64, macOS and Windows they behave as
0.8.8's.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`.
