Pi-Bolt 0.9.4 brings fixes from upstream Bun and WebKit into its engine: Pi-Bolt no longer stops at launch on some ARM64
CPUs, and child processes, timers and connections behave better. Pi is the same as in [0.9.3](0.9.3.md).

### Fixes

- **Linux on ARM64 and Android:** Pi-Bolt no longer stops at launch with an illegal instruction on CPUs that report SVE2
  without SVE (oven-sh/bun#45099).
- **Commands run by Pi:** a child process no longer inherits a non-blocking stdout or stderr, so a program that does not
  expect one no longer fails or loses output, and output written while the pipe is full is no longer dropped
  (oven-sh/bun#43868). A pipe is no longer read again after a read on it failed (oven-sh/bun#43900).
- **Timers while streaming:** a connection whose peer keeps the receive buffer full no longer stops timers such as the spinner
  and timeouts (oven-sh/bun#45278).
- **Model requests:** fetch sets up TLS once per connection instead of once per request (oven-sh/bun#44507). Over HTTP/2, a
  request is rejected on a TLS alert after the handshake, and a connection that went silent after an abort is no longer
  reused (oven-sh/bun#45422).
- **Plugins:** a module removed while its `import()` is still loading no longer crashes Pi-Bolt (oven-sh/WebKit#748).
- **Containers:** the memory limit of a cgroup v2 is seen where a cgroup v1 hierarchy exists beside it (oven-sh/WebKit#808).
- `spawnSync` (oven-sh/bun#44581) and `TextEncoder.encode` of a substring (oven-sh/bun#45281) are fixed, and the allocator is
  mimalloc 3.5.3 (oven-sh/bun#44560, oven-sh/bun#44575).

Measured on GitHub's runners (one CPU, the same Pi on 0.9.3's runtime and on 0.9.4's; x86-64 / ARM64): the startup peak memory
is 42 / 39 MB, from 53 / 42 MB. Time and CPU at startup, for a headless prompt, in an interactive session and while
streaming, and the memory left once idle, are within a few percent of 0.9.3's.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
irm https://pi-bolt.opensec.in/install.ps1 | iex
```

```bat
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`.
