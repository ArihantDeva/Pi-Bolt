Pi-Bolt 0.8.1 runs Pi 1.1.0 on Linux x86-64, macOS on Apple silicon and Windows x64. pi-fff works on the default build, and
installing with npm or Bun is easier.

### Extensions

- **pi-fff works without the JIT.** On the default build, pi-fff stopped at "FFF init failed: bun:ffi requires the JIT". It now
  uses its Node.js backend there (the same native search library), with nothing to set up; the `-jit` build uses its Bun backend
  as before.

### Install

- **npm and Bun:** `npm install -g --allow-scripts=pi-bolt pi-bolt` and `bun add -g --trust pi-bolt`. Both package managers now
  ask before running a package's install script, which on Windows puts the executable in place.
- When a build is not on npm yet, the installers say "not available from npm; downloading from GitHub instead", rather than
  that the download failed.

### Benchmarks

- 0.8.0 measured on Linux and macOS against Pi 1.1.0 on Bun and Node, and against PiG and oh-my-pi in the same runs
  ([docs/BENCHMARKS.md](../BENCHMARKS.md)). The site shows them too.

### Installer

- `install.sh` refuses checksums that say they are another release's, as `install.ps1` does: an older release, signed all the
  same, served as a newer one, is no longer installed as the newer.

### Engine

- On Windows: an idle keep-alive connection is aged on a clock nobody sets (GetTickCount64), as on Linux and macOS since 0.7.3.
- The writer of the prebuilt heap no longer stops at a pair of numbers that reads like an address of the builder's own memory;
  a word that could be a pointer there still stops it.

### Corrections to earlier notes

- 0.7.1 to 0.7.3 said the installer detects Linux or macOS: it is `install.sh` for those, and `install.ps1` for Windows.
- 0.7.1 said git sources are passed with `--end-of-options`. They are refused when the repository or ref starts with `-`, which
  works with every git version.

### Install

```bash
curl -fsSL https://pi-bolt.opensec.in/install.sh | sh
```

```powershell
powershell -c "irm https://pi-bolt.opensec.in/install.ps1 | iex"
```

or `pi-bolt update`, or `npm install -g --allow-scripts=pi-bolt pi-bolt`, or `bun add -g --trust pi-bolt`.

### The runtimes

hand ([RELEASING.md](../RELEASING.md#when-the-engine-changed)). From the engine trees that `patches/webkit.patch` and
`patches/bun.patch` make on the pinned sources (`git rev-parse HEAD^{tree}`): WebKit `f527504e0d1d9f14c73b7aab4682fe44972507fa`,
Bun `2c4f4980f78e0986a324aa46f648ce05542d9369`.
